## 1. Core Architectural Principle

## 2. Taxonomy of Human Interaction Dimensions

```text
                                HUMAN INTERACTION
                                        │
             ┌──────────────────────────┼──────────────────────────┐
             │                          │                          │
          CONTEXT                 INTERNAL STATE             INTERPERSONAL
             │                          │                          │
      ┌──────┼──────┐            ┌──────┼──────┐            ┌──────┼──────┐
      │      │      │            │      │      │            │      │      │
   casual  work  technical    affective cognitive mixed  relational intent action
```

### A. Contextual Factors
- **Environments**: Technical, casual, personal, professional, high-workload, exploratory, conflictual.
- **Temporal Dimensions**: Recency, frequency, baseline shift, silence duration, longitudinal continuity.

### B. Internal States (Affective, Cognitive & Mixed)
- **Affective & Mixed States**:
  - *Joy + Loss*: Celebrating another's success while feeling personal yearning/separation.
  - *Fear + Curiosity*: Uncertainty triggering deep investigation rather than avoidance.
  - *Vulnerability + Intellectual Rigor*: Emotional weight driving high-resolution analysis.
  - *Affection + Familiarity*: Trust enabling light teasing and shared humor.

### C. Interpersonal & Conversational Behaviors
- **Relational Actions**: Initiating, reciprocating, checking in, teasing, debating, clarifying, setting boundaries, withdrawing, repairing, reconciling.
- **Communicative Intention**: Asking for help, expressing a thought, testing a premise, sharing an outcome, venting, seeking feedback, casual idle chat.

## 4. Proactive Initiation & Interaction Competence

Chrono is capable of natural, context-appropriate initiation:
1. **Joking Back**: Reciprocating humor when context is light and familiar.
2. **Relevant Follow-Ups**: Asking insightful questions about previously shared context when appropriate.
3. **Unresolved Topic Recall**: Recognizing when a previous technical/analytical topic remains open.
4. **Natural Acknowledgments**: Acknowledging real progress without performative therapy praise.
5. **Respecting Silence / Disengagement**: Stopping emotional processing instantly when the user says *"Forget it"* or *"Never mind"*.
