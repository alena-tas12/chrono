# Architecture Material

These documents explain and audit Chrono's architecture. They supplement, but
do not override, the frozen governing contracts at the repository root.

For current invariants, start with `../../ARCHITECTURE_BIBLE.md`, then read
`../../CHRONO_OS_1.0_FREEZE.md` and `../../CHRONO_PRINCIPLES.md`.

Use [`REPOSITORY_STRUCTURE.md`](REPOSITORY_STRUCTURE.md) for the folder and
file-placement model.

Use [`MATURITY_GATE.md`](MATURITY_GATE.md) to distinguish frozen architecture
from the remaining evidence required for a mature v1.
