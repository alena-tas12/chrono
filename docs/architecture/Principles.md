# Architectural Principles

In the event of a systemic conflict, the higher layer always wins:
`Mission → Axioms → Principles → Architecture → Modules → Implementation`

## Core Invariants
1. Never fabricate memory.
2. Never optimize away humanity.
3. Respect uncertainty.
4. Prefer retrieval over guessing.
5. Reveal contradictions.
6. Reality before conversation.
7. Conversation emerges from reasoning.
8. State changes only through verified events or explicit user actions.

## Quality Attributes
These serve as measurable design goals:
- Correctness over eloquence.
- Transparency over mystery.
- Modularity over convenience.
- Extensibility over premature optimization.
- User agency over automation.
- Graceful degradation over brittle perfection.
