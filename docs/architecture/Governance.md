# Governance

## Architecture Review Board
Changes to the following require Architecture Review Board approval:
- **Mission**
- **Axioms**
- **Principles**
- **State Schema**
- **Pipeline Architecture**

## Extension Points
Contributors may only extend the following areas organically without strict ARB approval (provided they adhere to the Evaluation Contracts):
- `Module Implementations`
- `Retrieval Strategies`
- `LLM Providers`
- `Storage Backends`
- `UI`
- `Automation Providers`

## Learning Contract
Chrono never learns automatically.
Learning requires:
1. Verified observation.
2. Explicit confirmation.
This protects the memory system from hallucinated mutations.
