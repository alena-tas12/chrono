Quickstart & App Installation

How to install, launch, and initialize your local-first Chrono environment.

Chrono runs as a native desktop application powered by Electron and a high-performance local SQLite database. It requires zero cloud connectivity for its core offline features.

Step 1: Download & Run Installer

Download the latest Chrono Setup 2.2.0.exe from GitHub Releases or compile from source using npm:

# Clone the repository git clone https://github.com/alena10-05/chrono.git cd chrono # Install dependencies npm install # Run Chrono in development mode npm run dev

Step 2: Sign In or Use Offline Mode

You can immediately start creating notes, scheduling calendar tasks, and talking with local AI models in offline mode, or sign in via Google OAuth to enable cross-device Realtime replication.

Chrono Spaces & Collaborative Calendar PRs

How to create collaborative circles, propose events, and review calendar diffs.

Chrono Spaces operates like GitHub for human time and shared knowledge. Rather than letting anyone destructively overwrite your calendar, collaborators propose changes as "Calendar Pull Requests" (PRs).

Step 1: Open Chrono Spaces Drawer

Click the 👥 Spaces icon in the left-hand navigation rail. Click + Create Space and choose a space name (e.g., "AI Research Circle" or "Study Group").

Step 2: Propose an Event (Calendar PR)

Any contributor can propose a workshop, sprint review, or study session. Chrono automatically analyzes all member calendars for temporal conflicts:

// Automated conflict detection during proposal { "proposal_id": "pr_10827361", "space_id": "spc_ai_research", "title": "LLM Architecture Working Group", "start_time": "2026-08-18T15:00:00Z", "end_time": "2026-08-18T16:30:00Z", "status": "CLEAN", // Or "CONFLICT_DETECTED" "proposed_by": "Contributor" }

Step 3: Review and Merge Proposal

The Space Owner clicks Review Proposal. If clean, clicking Merge into Calendar instantly adds the event to all member workspaces and notifies peers over Supabase Realtime.

Communication OS: WebRTC, Meet & WhatsApp

How to add contacts, initiate encrypted peer calls, and launch instant external meeting rooms.

Communication OS provides a unified hub for peer relationships, direct messaging, and high-quality voice/video calling.

Step 1: Add a Contact

Click the 📞 Phone/Comms icon in the left rail. Click + Add Contact to save their name, phone number, and relationship role.

Step 2: Choose Communication Channel

  • 📞 CALL / 📹 VIDEO: Initiates direct peer-to-peer WebRTC encrypted voice/video with live timer.
  • 🌐 MEET: Instantly creates a Google Meet room (https://meet.google.com/new) in your default browser.
  • 💬 WHATSAPP: Uses native whatsapp://send?phone=... protocol to open the WhatsApp desktop application directly.
  • 🍏 FACETIME: Launches native Apple FaceTime audio/video call using facetime:<phone>.
  • Send (Encrypted DM): Stores direct messages locally and broadcasts via Supabase Realtime topic user:<id>:chat.

Knowledge Workspace & Block-Based Note System

How to organize notes, create flashcards, manage trash recovery, and link knowledge graphs.

Chrono's Knowledge Pillar gives you a Notion and RemNote inspired block-based canvas.

Key Actions & Workflows:

  • 📌 Pin / Unpin: Keep priority research documents at the top of your workspace.
  • 📄 Duplicate Note: Clone complex structured templates with full block hierarchies.
  • 🗑️ Soft-Delete & Trash Recovery: Delete notes safely without data loss. Restore anytime from the Trash tab or permanently purge.
  • 🔗 Bi-Directional Backlinks: Type [[Note Title]] to link concepts and view interconnected references in the knowledge graph.

Multi-Provider AI Gateway Configuration

How to configure Google Gemini, Groq, OpenRouter, or local offline Ollama models.

Chrono features an automatic multi-cloud AI routing pipeline that guarantees zero downtime. If one provider is rate-limited, it automatically falls back to the next healthy provider in milliseconds.

Configuring Your .env File:

# Primary AI Provider: Google Gemini GEMINI_API_KEY=your_gemini_api_key_here # Secondary Fast Cloud: Groq API GROQ_API_KEY=your_groq_api_key_here # Tertiary Cloud: OpenRouter OPENROUTER_API_KEY=your_openrouter_key_here # Local Offline Floor: Ollama OLLAMA_ENDPOINT=http://localhost:11434

Chrono will automatically route conversational queries through Google Gemini (gemini-flash-latest), falling back to Groq (llama-3.3-70b-versatile) with sub-second latency.

Supabase Realtime & Row-Level Security (RLS)

How multi-user data synchronization and topic security work.

Chrono uses WebSocket channels over Supabase Realtime to broadcast live calendar proposals, knowledge updates, and direct messages.

RLS Topic Enforcement:

All Realtime broadcast channels enforce PostgreSQL Row-Level Security based on channel topics:

-- Personal user event channel: user:<userId>:events -- Shared calendar space channel: calendar:<calendarId>:events CREATE POLICY "Enforce Realtime Topic Authorization" ON realtime.messages FOR SELECT TO authenticated USING ( (split_part(realtime.topic(), ':', 1) = 'user' AND split_part(realtime.topic(), ':', 2) = auth.uid()::text) OR (split_part(realtime.topic(), ':', 1) = 'calendar' AND EXISTS ( SELECT 1 FROM public.calendar_members WHERE calendar_members.calendar_id::text = split_part(realtime.topic(), ':', 2) AND calendar_members.user_id::text = auth.uid()::text )) );

Data Escape Hatch & Human Agency

Contract 14: You own your data. Export your entire life dataset anytime.

In adherence with Chrono's Core Contract 14 (Primacy of Human Agency), you are never locked into the platform. You can export your entire database at any time in industry-standard open formats:

  • 📅 iCalendar (.ics): Export all events, timetable schedules, and recurring milestones to Google Calendar, Apple Calendar, or Outlook.
  • 📊 CSV Format: Export relationship contacts, call histories, and task databases.
  • 📦 JSON Universal Export: Complete machine-readable backup of all notes, blocks, memory belief graphs, and conversation trees.
