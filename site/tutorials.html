Quickstart & App Installation

How to install, launch, and initialize your local-first Chrono environment.

Chrono runs as a native desktop application powered by Electron and a high-performance local SQLite database. It requires zero cloud connectivity for its core offline features.

Step 1: Download & Run Installer

Download the latest Chrono Setup 2.2.0.exe from GitHub Releases or compile from source using npm:

Terminal / PowerShellBash Commands
# 1. Clone the repository git clone https://github.com/alena10-05/chrono.git cd chrono # 2. Install all dependencies (Electron & SQLite) npm install # 3. Run Chrono in development mode npm run dev

Step 2: Sign In or Use Offline Mode

You can immediately start creating notes, scheduling calendar tasks, and talking with local AI models in offline mode, or sign in via Google OAuth to enable cross-device Realtime replication.

Chrono Spaces: Universal Containers & Change Proposals

How to create public/private spaces, toggle modular capabilities, and review governed Change Proposals.

Chrono Spaces is a general collaboration primitive. Rather than forcing you into a rigid "GitHub clone" or "Teams clone", Spaces allows visibility (Public vs. Private) and capabilities (Knowledge, Files, Issues, Change Proposals, Calendar, Chat, Calls, AI) to be toggled independently.

1. The 4 Emergent Flavors of Spaces:

  • 🚀 Public Project Space: Public visibility + Knowledge + Files + Issues + Proposals + AI (GitHub-style open development).
  • 🏢 Private Team Space: Private visibility + Knowledge + Files + Threaded Chat + Calls + Shared Calendar (Teams/Workspace-style).
  • 🗺️ Planning / Personal Space: Private visibility + Notes + Tasks + Calendar without heavy PR machinery.
  • 🌐 Community Space: Public visibility + Living Docs + Threaded Discussion + Direct Link or Discoverable directory.

2. Unified Role & Permission Matrix:

🛡️ Role Hierarchy (Orthogonal to Visibility)
• Owner: Full control (delete space, change visibility, manage roles, toggle capabilities).
• Admin: Space management except deletion.
• Maintainer: Toggle capabilities, manage members, review & merge proposals.
• Member: Full read/write across all enabled capabilities.
• Contributor: Read/write on content (issues, files, knowledge) without role admin rights.
• Viewer: Read-only access across enabled capabilities.
• Guest: Scoped permissions restricted to specific capabilities (e.g., chat only).

3. The Governed Change Proposal Lifecycle:

Whether proposing calendar events, knowledge base revisions, or task schedules, updates follow an atomic, governed review lifecycle:

Governed Proposal SchemaJSON Payload
{ "proposal_id": "prop_94827104", "space_id": "spc_research_collective", "type": "CALENDAR_EVENT", // Can be CALENDAR_EVENT, DOCUMENT_DIFF, or TASK "title": "Cross-Team Cognitive Alignment Workshop", "payload": { "start_time": "2026-08-18T14:00:00Z", "end_time": "2026-08-18T15:30:00Z", "location": "WebRTC Room #4" }, "status": "CLEAN", // Evaluated automatically against all member schedules "proposed_by": "usr_contributor_01" }
🔍 Conflict Detection & Atomic Merging
Chrono checks all member calendar events and document versions locally before proposing. Maintainers click Merge Proposal to atomically commit the change to local SQLite and broadcast updates across all active peers.

Communication OS: WebRTC, Meet & WhatsApp

How to add contacts, initiate encrypted peer calls, and launch instant external meeting rooms.

Communication OS provides a unified hub for peer relationships, direct messaging, and high-quality voice/video calling.

Step 1: Add a Contact

Click the 📞 Phone/Comms icon in the left rail. Click + Add Contact to save their name, phone number, and relationship role.

Step 2: Choose Communication Channel

  • 📞 CALL / 📹 VIDEO: Initiates direct peer-to-peer WebRTC encrypted voice/video with live timer.
  • 🌐 MEET: Instantly creates a Google Meet room (https://meet.google.com/new) in your default browser.
  • 💬 WHATSAPP: Uses native whatsapp://send?phone=... protocol to open the WhatsApp desktop application directly.
  • 🍏 FACETIME: Launches native Apple FaceTime audio/video call using facetime:<phone>.
  • Send (Encrypted DM): Stores direct messages locally and broadcasts via Supabase Realtime topic user:<id>:chat.

Knowledge Workspace & Block-Based Note System

How to organize notes, create flashcards, manage trash recovery, and link knowledge graphs.

Chrono's Knowledge Pillar gives you a Notion and RemNote inspired block-based canvas.

Key Actions & Workflows:

  • 📌 Pin / Unpin: Keep priority research documents at the top of your workspace.
  • 📄 Duplicate Note: Clone complex structured templates with full block hierarchies.
  • 🗑️ Soft-Delete & Trash Recovery: Delete notes safely without data loss. Restore anytime from the Trash tab or permanently purge.
  • 🔗 Bi-Directional Backlinks: Type [[Note Title]] to link concepts and view interconnected references in the knowledge graph.

AI Provider Routing & Adaptive Interaction Layer

How to configure multi-cloud failover, switch active models, and benefit from personalized interaction calibration.

Chrono runs an intelligent multi-provider reasoning pipeline with sub-second failover across OpenRouter → Groq → Local Ollama → Google Gemini. You can switch your preferred reasoning engine on the fly directly inside the desktop interface.

🔑 Supported AI Providers
• OpenRouter API (Primary): Multi-model access (GPT-4o Mini, Claude 3.5 Sonnet) at openrouter.ai.
• Groq API (Ultra-Fast Secondary): Sub-second LLaMA 3.3 70B inference at console.groq.com.
• Local Ollama (Offline Fallback): 100% private, local offline execution from ollama.ai.
• Google Gemini (Cloud Reasoning): High-speed multimodal analysis via aistudio.google.com.

1-Click Interactive Provider Switcher

Click the green status badge (e.g. OpenRouter · Active) in the top-right corner of the AI Chat header to open the Active Model & System Health diagnostics modal. From there, you can choose Auto-Failover or lock your preference to any connected provider.

The Adaptive Interaction Layer

Chrono continuously discovers each person's unique communication style (concise vs. deep vs. fragmented think-aloud) without retraining model weights:

  • 📊 Preference Inference: Inferred preferences gain confidence with repeated evidence, while session overrides (*"Actually go deep on this one"*) take instant priority.
  • 🛡️ Self-Correction as Evidence: Saying *"No, that's wrong"* triggers context re-evaluation rather than blind fact destruction.
  • 🔒 Zero Cross-User Leakage: All learned interaction calibrations are strictly scoped to the active user's local SQLite database.

Supabase Realtime & Row-Level Security (RLS)

How multi-user collaboration and private data streams stay isolated.

Chrono uses WebSocket topics over Supabase Realtime to broadcast live calendar proposals, knowledge updates, and direct messages without exposing private user data.

🛡️ Security Invariant: Isolated Topics
• Personal Channels (user:<userId>:events): Only the specific authenticated user can subscribe and listen.
• Collaborative Space Channels (calendar:<calendarId>:events): Only verified members of that specific space can receive broadcast events.

PostgreSQL Row-Level Security (RLS) Policy:

Database PolicyPostgreSQL DDL
-- Secure broadcast delivery policy on realtime.messages CREATE POLICY "Enforce Realtime Topic Authorization" ON realtime.messages FOR SELECT TO authenticated USING ( -- Branch 1: User's private personal channel (split_part(realtime.topic(), ':', 1) = 'user' AND split_part(realtime.topic(), ':', 2) = auth.uid()::text) OR -- Branch 2: Collaborative Chrono Space channel (membership verified) (split_part(realtime.topic(), ':', 1) = 'calendar' AND EXISTS ( SELECT 1 FROM public.calendar_members WHERE calendar_members.calendar_id::text = split_part(realtime.topic(), ':', 2) AND calendar_members.user_id::text = auth.uid()::text )) );

Data Escape Hatch & Human Agency

Contract 14: You own your data. Export your entire life dataset anytime.

In adherence with Chrono's Core Contract 14 (Primacy of Human Agency), you are never locked into the platform. You can export your entire database at any time in industry-standard open formats:

  • 📅 iCalendar (.ics): Export all events, timetable schedules, and recurring milestones to Google Calendar, Apple Calendar, or Outlook.
  • 📊 CSV Format: Export relationship contacts, call histories, and task databases.
  • 📦 JSON Universal Export: Complete machine-readable backup of all notes, blocks, memory belief graphs, and conversation trees.
