System Architecture

The 15-Layer Continuous Cognitive Pipeline

Every turn of dialogue, task scheduling, or memory retrieval executes through an uncompromising 15-stage reasoning lifecycle.

Stages 1 to 8: Ingestion, Disambiguation & Dispatch

  • 01
    Input Sanitization & Boundary Normalization
    Strips formatting artifacts, normalizes unicode, and parses spatial-temporal anchors.
  • 02
    Context Conflict & Anomaly Detector
    Detects conflicting user directives, logical contradictions, or impossible timetables.
  • 03
    Semantic Intent Classifier
    Classifies inputs into conversational, operational, knowledge inquiry, or relational tasks.
  • 04
    Evidence-First Hypothesis Engine
    Evaluates grounded user history without relying on fake pre-seeded assumptions.
  • 05
    Selective Module Dispatch & Boundary Exclusion
    Selectively fetches from Knowledge Base, Calendar, or Memory while strictly excluding irrelevant pillars.
  • 06
    Context Compression & Token Optimization
    Compresses conversation history into dense semantic representations to prevent context blowout.
  • 07
    Multi-Provider AI Routing Gateway
    Executes generation across Google Gemini, Groq, OpenRouter, or Local Ollama with live failover.
  • 08
    Epistemic Humility & Hallucination Guard
    Enforces explicit contract to honestly report lack of knowledge when records are absent.

Stages 9 to 15: Synthesis, Reflection & State Commit

  • 09
    Cognitive Pace & Response Depth Calibrator
    Dynamically adapts verbosity (Concise, Balanced, Deep) based on active user pacing signals.
  • 10
    Contract 14: Primacy of Human Agency
    Ensures advice returns autonomy to the user rather than dictating life decisions.
  • 11
    Branching Tree Assembler
    Appends turn to active leaf node in workspace conversation tree without cross-branch bleed.
  • 12
    Episodic Memory Ledger Update
    Extracts key entities, shared milestones, and relationship graph updates into local SQLite.
  • 13
    Realtime WebSocket Broadcast
    Emits change notifications to authorized user and space topics via Supabase Realtime.
  • 14
    Observatory Coherence & Telemetry Ingestion
    Logs response latency, model tokens, entropy shifts, and loop detection metrics.
  • 15
    Atomic Persistence & Transaction Commit
    Commits state to write-ahead log (WAL) SQLite with instant durability.
